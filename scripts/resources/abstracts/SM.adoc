// @overview
Abstract service interfaces for a complete openEHR platform, covering EHR, Query, Definitions, Demographics, Admin, and Terminology services. Includes the Simplified Information Model (SIM-B) and serial data formats for REST contexts.

// @spec:openehr_platform
Abstract service interface model for a complete openEHR platform. Defines formal service interfaces for EHR, Query, Definitions, Demographics, Admin, and Terminology access, independent of transport technology.

// @spec:simplified_im_b
A reduced-complexity data model intended for integrators and application developers who need to work with openEHR data over REST without implementing the full Reference Model. SIM-B trades some expressiveness for a flatter, more directly serialisable structure, lowering the tooling and implementation overhead for common integration scenarios.

// @spec:serial_data_formats
Serialisation formats for openEHR data in REST API contexts. Specifies JSON and XML conventions for encoding RM instances in request and response payloads, aligned with the openEHR REST API specifications.
