// @overview
XSD schemas for validating XML-encoded openEHR data, covering the Reference Model, Archetype Model (AM 1.4 and AM 2), BASE types, and AQL query structures.

// @spec:ITS-XML-RM
XSD schemas for validating XML-encoded openEHR Reference Model instances, covering the EHR, data types, data structures, common, and support packages. The schemas cover all RM packages with explicit namespace declarations and are used for validating XML payloads in legacy openEHR integrations. They are used in systems that have not yet migrated to JSON-based REST APIs or that require XML for document-oriented transport scenarios.

// @spec:ITS-XML-AM
XSD schemas for validating XML-encoded Archetype Model 1.4 artefacts, including ADL 1.4 archetypes and operational templates in their XML serialisation. These schemas are used by tools that import or export ADL 1.4 artefacts in XML form, such as legacy template designers and repository connectors. The XML serialisation follows the AOM 1.4 class structure, providing a direct mapping from the in-memory object model to XML elements.

// @spec:ITS-XML-AM2
XSD schemas for validating XML-encoded Archetype Model 2 artefacts, supporting ADL 2 archetypes and OPT2 operational templates. They provide a machine-validated interchange format for ADL 2 tooling that prefers XML over the native ADL text syntax. The schemas follow the AOM 2 class hierarchy, supporting differential and flat archetype forms as well as the OPT2 template format.

// @spec:ITS-XML-BASE
XSD schemas for validating XML-encoded openEHR BASE types including foundation types, base types, and resource model instances. These schemas are imported by the RM, AM, and other XML schema sets as shared type definitions. Implementers building XML-based openEHR integrations should include these schemas as dependencies in their validation pipelines.

// @spec:ITS-XML-OET
XSD schemas for the openEHR Exchange Template format, an XML serialisation used by legacy ADL 1.4 tooling and integrations for operational template exchange. OET files are produced by tools such as the openEHR Template Designer and consumed by form-rendering engines in legacy ADL 1.4 deployments. New implementations should prefer the OPT2 format; this schema is maintained for backward compatibility with existing tooling.

// @spec:ITS-XML-QUERY
XSD schemas for validating XML-encoded AQL query structures, covering query request and response message formats. The schemas cover AQL query request messages and tabular result set responses, enabling XML-based query integration with openEHR platforms. They are used in messaging-based integration scenarios where query exchange occurs over document-oriented transports.

// @spec:ITS-XML-v1
Combined XSD schema package for all openEHR v1 XML data formats. Provides a unified schema set for tools requiring comprehensive XML validation across the full openEHR model hierarchy. This package is the recommended starting point for integrators who need to validate any openEHR XML data without assembling individual schema dependencies. It is versioned as a unit, ensuring that all included schemas are mutually consistent and reference-compatible.
