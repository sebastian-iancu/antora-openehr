// @overview
OpenAPI specifications for the openEHR REST APIs: EHR, Query, Definition, System, Demographic, Admin, and SMART on openEHR. The core APIs (EHR, Query, Definition) are stable and in production use across implementations.

// @spec:overview
Overview of the openEHR REST API suite. Describes API design principles, shared conventions, versioning, authentication approach, and the relationships between the individual openEHR REST API specifications.

// @spec:system
REST API for system-level operations: server capability discovery, version information, status queries, and administrative metadata endpoints used by clients before interacting with EHR data.

// @spec:ehr
REST API for Electronic Health Record operations: creating and retrieving EHRs, managing Compositions and Contributions, accessing EHR Status, and querying versioned clinical content.

// @spec:query
REST API for executing Archetype Query Language queries against EHR data. Supports both stored query execution by name and ad-hoc query submission with parameter binding.

// @spec:definition
REST API for managing clinical knowledge artefacts: uploading, versioning, and retrieving archetypes, templates, and stored AQL queries on an openEHR platform.

// @spec:demographic
REST API for demographic service operations: creating, retrieving, and searching Party records representing persons, organisations, and roles in the openEHR demographic model.

// @spec:admin
REST API for platform administration tasks: EHR deletion, system configuration queries, and bulk data management operations reserved for privileged administrative clients.

// @spec:simplified_formats
Simplified JSON and XML formats for use with openEHR REST APIs. Provides a more compact, approachable data representation for common EHR data exchange scenarios and integration use cases.

// @spec:smart_app_launch
SMART on openEHR profile enabling SMART App Launch protocol integration with openEHR platforms. Defines the authentication and authorisation flow for standards-based application access to EHR data.

// @spec:REST_OAS_files
OpenAPI Specification files for the openEHR REST APIs. Machine-readable API definitions used for client code generation, interactive documentation, and automated conformance testing.
