// @overview
Task Planning model for adaptive, executable, team-based clinical workflows. Includes the TP-VML visual notation for designing care plans, a decision rule language, and real-world clinical process examples.

// @spec:overview
Overview of the openEHR approach to clinical decision support, guideline execution, and workflow coordination. Positions Task Planning, Decision Language, and GDL within the platform and describes their interactions.

// @spec:task_planning
Formal model for executable, team-based clinical workflow. Defines Work Plans, Task Plans, task types, conditional branching, event handling, performer roles, and the complete task lifecycle state machine.

// @spec:decision_language
Formal rule and expression language for computable clinical decision logic. Designed for use with GDL3 guideline engines and Task Planning workflow conditions, supporting complex multi-variable clinical rules.

// @spec:tp_vml
Visual Modelling Language for Task Planning: a graphical notation for designing, communicating, and validating clinical care plans and workflow structures using standardised diagram elements.

// @spec:process_examples
Worked examples of clinical process artefacts illustrating Task Planning, Decision Language, and GDL in real-world care pathway and guideline scenarios, covering common hospital and ambulatory care workflows.
