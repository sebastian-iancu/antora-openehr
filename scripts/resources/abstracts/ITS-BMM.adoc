// @spec:ITS-BMM
BMM schema files for openEHR information models. Machine-readable model definitions consumed by modelling tools, validators, and code generators to introspect and validate openEHR model structure. The schemas cover all openEHR information models including RM, AM 1.4, AM 2, BASE, and LANG, and are maintained in step with the corresponding specification releases. Modelling tools such as the openEHR ADL Workbench load these schemas at startup to drive archetype validation, class browser views, and constraint type resolution.
