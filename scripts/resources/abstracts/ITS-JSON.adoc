// @overview
JSON Schema definitions for validating JSON-encoded openEHR data across all information models. Used by implementations to verify request and response payloads against the REST APIs.

// @spec:ITS-JSON-Overview
Overview of the openEHR JSON Schema suite. Describes schema organisation, versioning, and the mapping between JSON Schema definitions and the openEHR information model hierarchy. It explains how JSON Schema draft versions are managed, how polymorphic RM types are discriminated using the _type field, and how optional and mandatory properties are encoded. Implementers building JSON serialisers or deserialisers for openEHR data should start with this overview before consulting the individual schema files.

// @spec:ITS-JSON
JSON Schema definitions for validating JSON-encoded openEHR data. Covers the Reference Model, Archetype Model, and BASE types used in REST API request and response payloads. Schemas are generated from the authoritative BMM model definitions to ensure consistency with the RM class hierarchy and property types. They are used in CI pipelines to validate openEHR platform responses and can be used directly in OpenAPI definitions to document expected payload structures.
