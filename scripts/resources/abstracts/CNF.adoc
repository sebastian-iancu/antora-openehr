// @overview
Framework for certifying openEHR platform implementations. Defines conformance profiles, test cases per REST API endpoint, and a certificate scheme for verifying vendor compliance against the openEHR specifications.

// @spec:guide
Comprehensive guide to the openEHR conformance framework. Covers conformance profiles, test categories, assessment methodology, and the certification process for platform implementations.

// @spec:platform_test_schedule
Detailed test schedule specifying test cases for each openEHR REST API endpoint and service interface, used to verify and document platform implementation conformance.

// @spec:profiles
Definitions of conformance profiles grouping REST API capabilities into coherent subsets. Enables partial conformance claims for implementations supporting specific functionality rather than the full API surface.

// @spec:certificate
Specification of the openEHR conformance certificate scheme. Defines how conformance assessment results are documented, structured, and published for certified platform implementations.
