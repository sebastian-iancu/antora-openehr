// @overview
Foundation of the openEHR specification stack. Covers the global Architecture Overview, primitive and structured types, identifiers and object references, and the Resource model for authored translatable documents.

// @spec:architecture_overview
Read-first introduction to the openEHR specification stack. Covers the multi-level modelling paradigm, principal components, relationships between specifications, and the global design philosophy of the platform.

// @spec:foundation_types
Primitive and structured types assumed by all openEHR specifications: Boolean, Integer, Real, String, Date, Time, DateTime, Duration, and generic containers such as List, Set, and Interval.

// @spec:base_types
Core identifier and reference types shared across the openEHR specification stack: object identifiers, version identifiers, terminology codes, and typed object references.

// @spec:resource
Model for authored, translatable, versioned documents. Provides the common structure for all openEHR artefacts requiring author metadata, language support, and annotation capability.

// @spec:iso_18308_conformance_statement
Formal mapping of the openEHR architecture to ISO TS 18308, demonstrating how each EHR architecture requirement defined in the standard is satisfied by the openEHR platform.
