// @overview
XSD schemas for validating XML-encoded openEHR data, covering the Reference Model, Archetype Model (AM 1.4 and AM 2), BASE types, and AQL query structures.

// @spec:ITS-XML-RM
XSD schemas for validating XML-encoded openEHR Reference Model instances, covering the EHR, data types, data structures, common, and support packages.

// @spec:ITS-XML-AM
XSD schemas for validating XML-encoded Archetype Model 1.4 artefacts, including ADL 1.4 archetypes and operational templates in their XML serialisation.

// @spec:ITS-XML-AM2
XSD schemas for validating XML-encoded Archetype Model 2 artefacts, supporting ADL 2 archetypes and OPT2 operational templates.

// @spec:ITS-XML-BASE
XSD schemas for validating XML-encoded openEHR BASE types including foundation types, base types, and resource model instances.

// @spec:ITS-XML-OET
XSD schemas for the openEHR Exchange Template format, an XML serialisation used by legacy ADL 1.4 tooling and integrations for operational template exchange.

// @spec:ITS-XML-QUERY
XSD schemas for validating XML-encoded AQL query structures, covering query request and response message formats.

// @spec:ITS-XML-v1
Combined XSD schema package for all openEHR v1 XML data formats. Provides a unified schema set for tools requiring comprehensive XML validation across the full openEHR model hierarchy.
